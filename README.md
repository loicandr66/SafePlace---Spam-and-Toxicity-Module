# SafePlace---Spam-and-Toxicity-Module
SafePlace est une extension web qui scannera les parties textes d'une page web et déterminera si le contenu est une arnaque, une fake news, un propos toxique/haineux, ou le contenu est un rabbit hole (Sujet répétitif dans plusieurs contenus successifs)
